# 微信读书同步

将微信读书的**书籍、划线与想法**同步到思源笔记，并在思源内检索、浏览与调用这些笔记。

## 核心特性

- **二维码登录 + Cookie 兜底**：主路径为微信扫码登录；若思源环境受限，可通过浏览器复制 Cookie 手动登录。
- **全量/快速同步**：支持「同步全部」与「仅同步有笔记的书」两种模式，书架规模大时也能断点续传。
- **增量追加，不覆盖本地编辑**：首次同步后，你在思源中做的任何批注、整理、重写都不会被后续同步覆盖。
- **冲突双版本共存**：同一条笔记在思源和微信读书两端都被修改时，保留思源版本，并追加微信读书的更新版本，各自带时间戳。
- **远端删除本地保留**：在微信读书中删除的笔记，思源端保留原文并标注「已在微信读书删除」，绝不静默丢数据。
- **思源内调用**：通过斜杠命令 `/weread`、`/读书` 或 Dock 面板的「插入」按钮，将已有笔记以**块引用**形式插入当前文档。
- **移动端只读**：桌面端负责同步与写入，移动端可浏览书架与笔记内容。

## 安装

1. 在思源笔记「设置 - 集市」中点击「下载 - 本地安装」，选择本仓库生成的 `package.zip`。
2. 启用插件后，点击顶栏的「微信读书」图标打开 Dock 面板。

## 使用步骤

1. **登录**
   - 打开 Dock 面板，使用微信扫描二维码登录。
   - 若二维码不可用，点击「手动粘贴 Cookie」，在浏览器登录 `weread.qq.com` 后复制 Cookie 粘贴。

2. **同步**
   - 点击「同步全部」：遍历书架，为每本有笔记的书生成/更新一篇思源文档。
   - 点击「快速同步」：仅同步「有笔记的书」，耗时更短。
   - 同步过程中可点击「取消」，已完成的部分会保留；下次同步可从中断处继续。

3. **查看与调用**
   - 在 Dock 面板中浏览书架，点击书名可在思源中打开对应笔记文档。
   - 点击某条笔记的「插入」按钮，即可在当前光标处插入该笔记的块引用。
   - 在编辑器中输入 `/weread` 或 `/读书`，可搜索并插入任意已同步笔记。

4. **设置**
   - 右键顶栏图标，选择「设置」可配置：目标笔记本、同步范围、并发数、请求间隔、斜杠命令触发词、定时同步等。

## 数据说明

- 登录凭证（Cookie）仅保存在思源数据目录的插件存储区，**不会上传到任何第三方服务器**。
- 封面图默认缓存在插件内存中，不写入思源文档，也不进入思源同步数据。
- 同步目标为「有笔记的书」；没有笔记的书只会在插件书架列表中展示，不会生成空文档。

## 已知限制

- 思源 `POST /api/network/forwardProxy` 接口要求管理员权限，因此在 **Docker 多用户部署的非管理员账号** 下无法使用。
- 微信读书接口均为非官方逆向接口，可能随官方更新而变动。插件会给出明确的错误提示。
- 1.0.0 版本不支持将思源的修改反向写回微信读书。

## 与同类插件的差异

现有的 `siyuan-plugin-weread` 已停更约两年半，并采用**覆盖式更新**，明确提示「请不要在同步的文件里修改内容」。本插件从设计之初就以保护本地编辑为前提，采用「增量追加 + 三方比对」策略，你在思源里的二次创作不会被覆盖。
